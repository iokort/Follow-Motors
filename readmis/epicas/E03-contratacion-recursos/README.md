# E03 — Contratación y recursos

**Objetivo:** Convertir el diagnóstico en un acuerdo presencial con precio, anticipo, garantía de taller y refacciones por proveedor externo.

**Reglas relacionadas:** NEG-14 a NEG-26.

**Fuera de esta épica:** Inventario de proveedor, margen sobre piezas, cobro duplicado del diagnóstico.

## Historias de usuario

- [US07 — Presupuestar y acordar reparación presencial](US07.md) · Prioridad alta · 8 tarjetas CRC
- [US08 — Cobrar anticipo y entregar garantía de taller](US08.md) · Prioridad alta · 8 tarjetas CRC
- [US09 — Asignar mecánico y gestionar refacciones externas](US09.md) · Prioridad alta · 8 tarjetas CRC

## Criterio de cierre de la épica

Las tres historias deben satisfacer sus criterios de aceptación con pruebas y recorrido completo entre aplicaciones pertinentes, API C# y MySQL. Ninguna historia se considera implementada porque exista su README. Los permisos se verifican **en el servidor** y los datos de ejemplo no se atribuyen a clientes reales.
