# E01 — Identidad y expedientes

**Objetivo:** Registrar personas y motocicletas presencialmente y ofrecer consulta privada de expedientes sin convertir el taller en una tienda.

**Reglas relacionadas:** NEG-01 a NEG-08, NEG-38.

**Fuera de esta épica:** Registro público, catálogo de venta, mensajes a correos ficticios.

## Historias de usuario

- [US01 — Alta presencial y control de cuentas](US01.md) · Prioridad alta · 7 tarjetas CRC
- [US02 — Registrar motocicleta y vincular propietario](US02.md) · Prioridad alta · 7 tarjetas CRC
- [US03 — Acceder al portal y consultar datos propios](US03.md) · Prioridad alta · 7 tarjetas CRC

## Criterio de cierre de la épica

Las tres historias deben satisfacer sus criterios de aceptación con pruebas y recorrido completo entre aplicaciones pertinentes, API C# y MySQL. Ninguna historia se considera implementada porque exista su README. Los permisos se verifican **en el servidor** y los datos de ejemplo no se atribuyen a clientes reales.
