# US11 — Cancelar y calcular reembolso antes del 60 %

**Épica:** [E04 — Ejecución, seguimiento y cierre](README.md)  
**Prioridad:** Alta  
**Dependencias funcionales:** US08, US09, US10  
**Reglas:** `NEG-26`, `NEG-28`, `NEG-31`, `NEG-32`, `NEG-33`, `NEG-34`, `NEG-35`

## Historia de usuario

**Como** cliente con cuenta activa, **quiero** solicitar cancelación de una reparación y conocer la devolución correspondiente, **para** pagar solo trabajo realizado y piezas usadas cuando todavía se permite cancelar.

## Flujo principal

1. Cliente envía solicitud desde Angular para una orden propia.
2. La API bloquea la orden, fija progreso verificable y confirma que no supera 60 %.
3. Si permite cancelar, congela ejecución y calcula trabajo ejecutado más piezas usadas.
4. Registra refacciones nuevas pendientes de devolución y calcula importe a reembolsar desde anticipo.
5. Si supera 60 %, rechaza cancelación sin detener el servicio; el taller continúa hasta entregarlo.

## Criterios de aceptación

1. Un cliente no puede cancelar una orden ajena ni una atención que no sea reparación contratada.
2. A 60 % exactos se permite; a más de 60 % se rechaza y el servicio se termina normalmente.
3. Reembolso autorizado = anticipo reparación − (mano de obra efectiva + piezas usadas), sin revisión fija.
4. Refacciones no usadas no se cobran y se registran para retorno al proveedor.
5. Cancelar mientras se registra una tarea produce una sola decisión consistente; no hay doble devolución.
6. El cliente ve decisión y desglose; un rechazo no cancela ni congela la orden.

**Alternativas y errores a probar:** Concurrencia avance/cancelación; refacción ya abierta; intento repetido; avance fuera de rango.

## Tarjetas CRC (8)

Cada fila es una **tarjeta CRC**: una clase candidata, su responsabilidad y sus colaboradores. Los nombres son analíticos, no archivos obligatorios; las clases compartidas se reutilizan entre historias y pueden consolidarse.

| Clase candidata | Responsabilidades | Colaboradores |
| --- | --- | --- |
| `SolicitudCancelacion` | Registrar petición, momento, solicitante y resolución. | OrdenServicio, PoliticaCancelacion |
| `PoliticaCancelacion` | Verificar estado de orden y límite de 60 %. | OrdenServicio, CalculadoraAvance |
| `CalculadoraReembolso` | Descontar mano de obra ejecutada y piezas usadas. | PagoAnticipado, RefaccionServicio |
| `OrdenServicio` | Mantener progreso y estado atómicos frente a cancelación. | SolicitudCancelacion, TareaServicio |
| `RefaccionServicio` | Distinguir usadas y nuevas retornables. | CalculadoraReembolso, OrdenServicio |
| `PagoAnticipado` | Ofrecer importe anticipado de reparación, sin diagnóstico. | CalculadoraReembolso, SolicitudCancelacion |
| `ServicioCancelaciones` | Coordinar bloqueo, resolución, devolución y auditoría. | PoliticaCancelacion, CalculadoraReembolso |
| `RegistroAuditoria` | Conservar avances y montos que sustentaron la resolución. | ServicioCancelaciones, SolicitudCancelacion |
