# E04 — Ejecución, seguimiento y cierre

**Objetivo:** Registrar tareas observables, permitir consultas y cancelaciones reguladas por avance, cerrar y documentar la reparación entregada.

**Reglas relacionadas:** NEG-27 a NEG-38.

**Fuera de esta épica:** Progreso basado solo en tiempo, cancelación con la moto inconclusa después del 60 %.

## Historias de usuario

- [US10 — Registrar tareas y mostrar progreso real](US10.md) · Prioridad alta · 7 tarjetas CRC
- [US11 — Cancelar y calcular reembolso antes del 60 %](US11.md) · Prioridad alta · 8 tarjetas CRC
- [US12 — Finalizar, entregar y consultar historial y garantía](US12.md) · Prioridad alta · 7 tarjetas CRC

## Criterio de cierre de la épica

Las tres historias deben satisfacer sus criterios de aceptación con pruebas y recorrido completo entre aplicaciones pertinentes, API C# y MySQL. Ninguna historia se considera implementada porque exista su README. Los permisos se verifican **en el servidor** y los datos de ejemplo no se atribuyen a clientes reales.
