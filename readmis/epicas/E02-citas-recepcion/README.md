# E02 — Citas y recepción

**Objetivo:** Organizar cupos de revisión y registrar ingresos y diagnósticos con precio fijo, independientemente de que se contrate una reparación.

**Reglas relacionadas:** NEG-09 a NEG-13.

**Fuera de esta épica:** Aprobación humana de citas en línea, autorización remota de reparaciones.

## Historias de usuario

- [US05 — Administrar horarios y cupos del taller](US05.md) · Prioridad alta · 7 tarjetas CRC
- [US06 — Recepcionar y cobrar la revisión](US06.md) · Prioridad alta · 7 tarjetas CRC

## Criterio de cierre de la épica

Las tres historias deben satisfacer sus criterios de aceptación con pruebas y recorrido completo entre aplicaciones pertinentes, API C# y MySQL. Ninguna historia se considera implementada porque exista su README. Los permisos se verifican **en el servidor** y los datos de ejemplo no se atribuyen a clientes reales.
