# Base de datos — Gael

Motor previsto: MySQL.

Guardar aquí:
- `migrations/`: scripts numerados y versionados, reversibles cuando sea posible.
- `seeds/`: datos de ejemplo **ficticios**.
- `schema/`: definiciones y diagramas exportables del modelo.
- `queries/`: consultas que merezcan versionarse.

No subir credenciales, respaldos de producción ni datos personales.

Toda modificación de tablas, claves, tipos o índices debe acordarse con Kort antes de integrarse. Las migraciones destructivas requieren aprobación específica. No crear tablas ficticias como si fueran el diseño aprobado.
