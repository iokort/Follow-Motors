# US05 — Administrar y corregir expedientes

**Épica:** [E02 — Expedientes y motocicletas](README.md) · **Issue:** [#20](https://github.com/iokort/Follow-Motors/issues/20) · **Prioridad:** Alta

**Historia:** Como gerente autorizado, quiero consultar y corregir registros de personas y motocicletas, para mantener información fiable sin perder historial.

**Dependencias:** US04. **Estado:** especificada; su implementación depende de PR y pruebas reales.

## Criterios de aceptación
- [ ] El gerente puede corregir errores dejando actor y fecha.
- [ ] Una transferencia de titular no elimina el histórico.
- [ ] Cliente sin autorización no puede editar propietario o VIN.

## Tarjetas CRC (12)

Las tarjetas siguientes definen **responsabilidad y colaboración propuestas**, no una obligación de implementar 12 clases individuales. Un mismo componente compartido puede aparecer en varias US.

### CRC-US05-01 · ExpedientesView

- **Componente / clase candidata:** `ExpedientesView`.
- **Responsabilidad:** Mostrar búsqueda, selección y edición autorizada.
- **Colaboradores:** ExpedientesViewModel.

### CRC-US05-02 · ExpedientesViewModel

- **Componente / clase candidata:** `ExpedientesViewModel`.
- **Responsabilidad:** Gestionar filtro, edición y mensajes de error.
- **Colaboradores:** ClienteApiExpedientes.

### CRC-US05-03 · Cliente

- **Componente / clase candidata:** `Cliente`.
- **Responsabilidad:** Exponer datos de contacto y estado del expediente.
- **Colaboradores:** RepositorioClientes.

### CRC-US05-04 · Motocicleta

- **Componente / clase candidata:** `Motocicleta`.
- **Responsabilidad:** Exponer VIN, modelo, titular y estado.
- **Colaboradores:** RepositorioMotocicletas.

### CRC-US05-05 · HistorialPropietarios

- **Componente / clase candidata:** `HistorialPropietarios`.
- **Responsabilidad:** Guardar vínculos anteriores de una motocicleta.
- **Colaboradores:** Motocicleta, Cliente.

### CRC-US05-06 · EditarExpedienteDto

- **Componente / clase candidata:** `EditarExpedienteDto`.
- **Responsabilidad:** Recibir campos permitidos de corrección.
- **Colaboradores:** ControladorExpedientes.

### CRC-US05-07 · ControladorExpedientes

- **Componente / clase candidata:** `ControladorExpedientes`.
- **Responsabilidad:** Validar permiso y dirigir edición al servidor.
- **Colaboradores:** GestorExpedientes.

### CRC-US05-08 · GestorExpedientes

- **Componente / clase candidata:** `GestorExpedientes`.
- **Responsabilidad:** Aplicar reglas de cambio sin destruir historial.
- **Colaboradores:** RepositorioClientes, RepositorioMotocicletas.

### CRC-US05-09 · TransferenciaTitular

- **Componente / clase candidata:** `TransferenciaTitular`.
- **Responsabilidad:** Cerrar vínculo anterior y abrir nuevo historial.
- **Colaboradores:** HistorialPropietarios, GestorExpedientes.

### CRC-US05-10 · RepositorioClientes

- **Componente / clase candidata:** `RepositorioClientes`.
- **Responsabilidad:** Consultar y actualizar datos autorizados.
- **Colaboradores:** Cliente, GestorExpedientes.

### CRC-US05-11 · RepositorioMotocicletas

- **Componente / clase candidata:** `RepositorioMotocicletas`.
- **Responsabilidad:** Persistir vinculación y consultar VIN único.
- **Colaboradores:** Motocicleta, TransferenciaTitular.

### CRC-US05-12 · AuditoriaCambios

- **Componente / clase candidata:** `AuditoriaCambios`.
- **Responsabilidad:** Conservar campos anteriores/nuevos, actor y momento.
- **Colaboradores:** GestorExpedientes, TransferenciaTitular.
