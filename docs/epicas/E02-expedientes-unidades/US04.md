# US04 — Alta presencial de clientes y unidades

**Épica:** [E02 — Expedientes y motocicletas](README.md) · **Issue:** [#19](https://github.com/iokort/Follow-Motors/issues/19) · **Prioridad:** Alta

**Historia:** Como gerente que ejerce como asesor, quiero registrar al cliente y vincularle una motocicleta verificada en sucursal, para darle acceso controlado al soporte posterior.

**Dependencias:** US21. **Estado:** especificada; su implementación depende de PR y pruebas reales.

## Criterios de aceptación
- [ ] Solo el gerente habilitado puede dar de alta y entregar credenciales.
- [ ] Un VIN ya registrado no puede duplicarse.
- [ ] Las cuentas no se crean desde la página pública; una moto CFMOTO puede vincularse al expediente autorizado.

## Tarjetas CRC (12)

Las tarjetas siguientes definen **responsabilidad y colaboración propuestas**, no una obligación de implementar 12 clases individuales. Un mismo componente compartido puede aparecer en varias US.

### CRC-US04-01 · FormularioAltaView

- **Componente / clase candidata:** `FormularioAltaView`.
- **Responsabilidad:** Mostrar los datos de alta presencial sin formulario público.
- **Colaboradores:** FormularioAltaViewModel.

### CRC-US04-02 · FormularioAltaViewModel

- **Componente / clase candidata:** `FormularioAltaViewModel`.
- **Responsabilidad:** Validar estado visual y orden de la operación.
- **Colaboradores:** ClienteApiAlta, FormularioAltaView.

### CRC-US04-03 · Cliente

- **Componente / clase candidata:** `Cliente`.
- **Responsabilidad:** Representar titular de expediente sin exigir cuenta activa.
- **Colaboradores:** RepositorioClientes.

### CRC-US04-04 · Usuario

- **Componente / clase candidata:** `Usuario`.
- **Responsabilidad:** Almacenar cuenta creada por personal autorizado y estado activo.
- **Colaboradores:** RepositorioUsuarios.

### CRC-US04-05 · Motocicleta

- **Componente / clase candidata:** `Motocicleta`.
- **Responsabilidad:** Vincular VIN, modelo, origen y titular actual.
- **Colaboradores:** RepositorioMotocicletas.

### CRC-US04-06 · RegistrarClienteDto

- **Componente / clase candidata:** `RegistrarClienteDto`.
- **Responsabilidad:** Transportar datos mínimos desde el asesor a la API.
- **Colaboradores:** ControladorAltas.

### CRC-US04-07 · ControladorAltas

- **Componente / clase candidata:** `ControladorAltas`.
- **Responsabilidad:** Exigir permiso registrar y revisar entradas HTTP.
- **Colaboradores:** RegistrarExpediente.

### CRC-US04-08 · RegistrarExpediente

- **Componente / clase candidata:** `RegistrarExpediente`.
- **Responsabilidad:** Coordinar cliente, cuenta opcional y motocicleta.
- **Colaboradores:** RepositorioClientes, RepositorioMotocicletas.

### CRC-US04-09 · RepositorioClientes

- **Componente / clase candidata:** `RepositorioClientes`.
- **Responsabilidad:** Insertar y localizar expedientes en MySQL V3.
- **Colaboradores:** Cliente, RegistrarExpediente.

### CRC-US04-10 · RepositorioMotocicletas

- **Componente / clase candidata:** `RepositorioMotocicletas`.
- **Responsabilidad:** Aplicar unicidad de VIN y propietario.
- **Colaboradores:** Motocicleta, ValidacionVIN.

### CRC-US04-11 · ValidacionVIN

- **Componente / clase candidata:** `ValidacionVIN`.
- **Responsabilidad:** Rechazar VIN inválido o duplicado.
- **Colaboradores:** RepositorioMotocicletas, RegistrarExpediente.

### CRC-US04-12 · AuditoriaAlta

- **Componente / clase candidata:** `AuditoriaAlta`.
- **Responsabilidad:** Trazar identidad del gerente y cambios de vinculación.
- **Colaboradores:** RegistrarExpediente, Usuario.
