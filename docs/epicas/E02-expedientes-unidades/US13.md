# US13 — Consultar kilometraje sin editarlo

**Épica:** [E02 — Expedientes y motocicletas](README.md) · **Issue:** [#28](https://github.com/iokort/Follow-Motors/issues/28) · **Prioridad:** Media

**Historia:** Como cliente autenticado, quiero ver el último kilometraje registrado en sus servicios, para consultar el avance de su motocicleta sin alterar su historial.

**Dependencias:** US02, US07. **Estado:** especificada; su implementación depende de PR y pruebas reales.

## Criterios de aceptación
- [ ] El cliente ve solo kilometrajes de motos propias.
- [ ] El odómetro no se puede editar desde el portal.
- [ ] El dato vacío se muestra sin inventar lecturas.

## Tarjetas CRC (12)

Las tarjetas siguientes definen **responsabilidad y colaboración propuestas**, no una obligación de implementar 12 clases individuales. Un mismo componente compartido puede aparecer en varias US.

- **Componente / clase candidata:** `KilometrajeView`.
