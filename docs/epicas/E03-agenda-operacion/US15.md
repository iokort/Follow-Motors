# US15 — Consultar, reprogramar y cancelar agenda

**Épica:** [E03 — Agenda y operación de taller](README.md) · **Issue:** [#30](https://github.com/iokort/Follow-Motors/issues/30) · **Prioridad:** Alta

**Historia:** Como gerente/asesor, quiero ver y cambiar las citas que administra la sucursal, para evitar horarios inconsistentes y conservar decisiones.

**Dependencias:** US06, US21. **Estado:** especificada; integración y pruebas pendientes hasta que existan PR verificables.

## Criterios de aceptación
- [ ] Solo el personal autorizado modifica citas.
- [ ] Se ven PROGRAMADA, CONFIRMADA, CANCELADA y REALIZADA según MySQL V3.
- [ ] Reprogramaciones y cancelaciones dejan rastro de quién modificó la cita.
