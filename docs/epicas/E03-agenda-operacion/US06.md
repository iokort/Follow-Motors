# US06 — Programar citas para cualquier marca

**Épica:** [E03 — Agenda y operación de taller](README.md) · **Issue:** [#21](https://github.com/iokort/Follow-Motors/issues/21) · **Prioridad:** Alta

**Historia:** Como gerente/asesor, quiero registrar una cita interna para una motocicleta CFMOTO o de otra marca, para organizar la atención del taller.

**Dependencias:** US21; datos de motocicleta registrada o contacto externo. **Estado:** especificada; integración y pruebas pendientes hasta que existan PR verificables.

## Criterios de aceptación
- [ ] El cliente no reserva directamente: la solicitud llega por WhatsApp y la registra el gerente.
- [ ] Se acepta una moto externa sin crear automáticamente una moto del portal.
- [ ] La cita queda ligada a fecha, hora, motivo, contacto y responsable.

## Tarjetas CRC (12)

Responsabilidades y colaboradores **de diseño**: no obligan a implementar 12 clases independientes ni a duplicar componentes compartidos.

### CRC-US06-01 · Cita

- **Componente / clase candidata:** `Cita`.
- **Responsabilidad:** Conservar fecha, duración, tipo de unidad, motivo y estado.
- **Colaboradores:** RepositorioCitas, GestorCitas.

### CRC-US06-02 · TipoMotocicletaCita

- **Componente / clase candidata:** `TipoMotocicletaCita`.
- **Responsabilidad:** Diferenciar unidad CFMOTO registrada de unidad EXTERNA.
- **Colaboradores:** Cita, ValidadorCita.

### CRC-US06-03 · ContactoExterno

- **Componente / clase candidata:** `ContactoExterno`.
- **Responsabilidad:** Guardar datos mínimos para cita de otra marca.
- **Colaboradores:** Cita, TipoMotocicletaCita.

### CRC-US06-04 · FormularioCitaView

- **Componente / clase candidata:** `FormularioCitaView`.
- **Responsabilidad:** Mostrar formulario de captura usado solo por personal.
- **Colaboradores:** FormularioCitaViewModel.

### CRC-US06-05 · FormularioCitaViewModel

- **Componente / clase candidata:** `FormularioCitaViewModel`.
- **Responsabilidad:** Exponer campos, validación visual y estado de guardado.
- **Colaboradores:** ClienteApiCitas.

### CRC-US06-06 · ClienteApiCitas

- **Componente / clase candidata:** `ClienteApiCitas`.
- **Responsabilidad:** Consumir API de agenda sin acceso MySQL.
- **Colaboradores:** ControladorCitas.

### CRC-US06-07 · CrearCitaDto

- **Componente / clase candidata:** `CrearCitaDto`.
- **Responsabilidad:** Transportar marca/contacto externos o motocicleta_id autorizada.
- **Colaboradores:** ValidadorCita, ControladorCitas.

### CRC-US06-08 · ControladorCitas

- **Componente / clase candidata:** `ControladorCitas`.
- **Responsabilidad:** Exigir permiso agenda.crear y procesar JSON.
- **Colaboradores:** GestorCitas, PoliticaAgenda.

### CRC-US06-09 · GestorCitas

- **Componente / clase candidata:** `GestorCitas`.
- **Responsabilidad:** Crear cita válida y asociar recursos sin inventar clientes.
- **Colaboradores:** RepositorioCitas, ValidadorCita.

### CRC-US06-10 · ValidadorCita

- **Componente / clase candidata:** `ValidadorCita`.
- **Responsabilidad:** Aplicar reglas para tipo CFMOTO o EXTERNA y rango horario.
- **Colaboradores:** TipoMotocicletaCita, Cita.

### CRC-US06-11 · RepositorioCitas

- **Componente / clase candidata:** `RepositorioCitas`.
- **Responsabilidad:** Persistir agenda usando tabla citas de MySQL V3.
- **Colaboradores:** Cita, GestorCitas.

### CRC-US06-12 · AuditoriaAgenda

- **Componente / clase candidata:** `AuditoriaAgenda`.
- **Responsabilidad:** Registrar autor, fecha y cambios en la programación.
- **Colaboradores:** GestorCitas, ContextoUsuario.
