# US16 — Registrar órdenes y trabajos de mecánico

**Épica:** [E03 — Agenda y operación de taller](README.md) · **Issue:** [#31](https://github.com/iokort/Follow-Motors/issues/31) · **Prioridad:** Media

**Historia:** Como mecánico de taller, quiero registrar mantenimiento con fecha, kilometraje y descripción, para entregar el servicio al gerente para su aprobación.

**Dependencias:** US06 o unidad autorizada; US21, US07. **Estado:** especificada; integración y pruebas pendientes hasta que existan PR verificables.

## Criterios de aceptación
- [ ] Un mecánico registra el trabajo, sin aprobarlo por sí solo.
- [ ] El trabajo inicia PENDIENTE y el gerente puede APROBAR o RECHAZAR.
- [ ] Se conserva historial de fechas, kilómetros y datos de verificación.

## Tarjetas CRC (12)

Responsabilidades y colaboradores **de diseño**: no obligan a implementar 12 clases independientes ni a duplicar componentes compartidos.

### CRC-US16-01 · Trabajo

- **Componente / clase candidata:** `Trabajo`.
- **Responsabilidad:** Representar fecha, odómetro, descripción y validación.
- **Colaboradores:** RepositorioTrabajos.

### CRC-US16-02 · Mecanico

- **Componente / clase candidata:** `Mecanico`.
- **Responsabilidad:** Identificar actor que realizó el servicio.
- **Colaboradores:** Trabajo, PoliticaTrabajo.

### CRC-US16-03 · CapturaTrabajoView

- **Componente / clase candidata:** `CapturaTrabajoView`.
- **Responsabilidad:** Presentar datos del trabajo y estado de registro.
- **Colaboradores:** CapturaTrabajoViewModel.

### CRC-US16-04 · CapturaTrabajoViewModel

- **Componente / clase candidata:** `CapturaTrabajoViewModel`.
- **Responsabilidad:** Conservar formulario, carga y resultado.
- **Colaboradores:** ClienteApiTrabajos.

### CRC-US16-05 · ClienteApiTrabajos

- **Componente / clase candidata:** `ClienteApiTrabajos`.
- **Responsabilidad:** Enviar trabajo para revisión por HTTP.
- **Colaboradores:** ControladorTrabajos.

### CRC-US16-06 · RegistrarTrabajoDto

- **Componente / clase candidata:** `RegistrarTrabajoDto`.
- **Responsabilidad:** Transportar motocicleta, descripción y kilometraje.
- **Colaboradores:** ValidadorTrabajo.

### CRC-US16-07 · ControladorTrabajos

- **Componente / clase candidata:** `ControladorTrabajos`.
- **Responsabilidad:** Verificar rol y formato antes de registrar.
- **Colaboradores:** RegistrarTrabajo.

### CRC-US16-08 · RegistrarTrabajo

- **Componente / clase candidata:** `RegistrarTrabajo`.
- **Responsabilidad:** Guardar trabajo PENDIENTE vinculado a unidad o cita.
- **Colaboradores:** RepositorioTrabajos, PoliticaTrabajo.

### CRC-US16-09 · ValidadorTrabajo

- **Componente / clase candidata:** `ValidadorTrabajo`.
- **Responsabilidad:** Comprobar odómetro no negativo y campos obligatorios.
- **Colaboradores:** RegistrarTrabajo, Trabajo.

### CRC-US16-10 · RepositorioTrabajos

- **Componente / clase candidata:** `RepositorioTrabajos`.
- **Responsabilidad:** Persistir trabajo y consultar pendientes.
- **Colaboradores:** Trabajo, ValidadorServicio.

### CRC-US16-11 · ValidadorServicio

- **Componente / clase candidata:** `ValidadorServicio`.
- **Responsabilidad:** Permitir APROBAR/RECHAZAR solo por gerente autorizado.
- **Colaboradores:** RepositorioTrabajos, PoliticaTrabajo.

### CRC-US16-12 · AuditoriaTrabajo

- **Componente / clase candidata:** `AuditoriaTrabajo`.
- **Responsabilidad:** Registrar registro, validación y correcciones.
- **Colaboradores:** Trabajo, ValidadorServicio.
