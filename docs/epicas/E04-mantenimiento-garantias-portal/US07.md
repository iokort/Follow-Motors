# US07 — Seguimiento de tres servicios y mantenimiento posterior

**Épica:** [E04 — Mantenimiento, garantías y portal del cliente](README.md) · **Issue:** [#22](https://github.com/iokort/Follow-Motors/issues/22) · **Prioridad:** Alta

**Historia:** Como gerente o mecánico autorizado, quiero registrar y verificar las etapas de mantenimiento, para conocer cuándo vence el siguiente servicio y mantener historial.

**Dependencias:** US04, US21; esquema de Gael. **Estado:** especificada; integración y pruebas pendientes hasta que existan PR verificables.

## Criterios de aceptación
- [ ] Se registran primer, segundo y tercer servicio, con fecha real y kilometraje.
- [ ] El retraso no impide guardar un servicio; se marca para decisión de garantía.
- [ ] Tras el tercero pueden continuar los servicios cada seis meses.
- [ ] Antes de codificar vencimientos se resuelve la discrepancia entre la conversación y SQL V3: meses de 3, 6 y 12 desde venta frente a intervalos entre servicios. No modificar unilateralmente los datos de Gael.

## Tarjetas CRC (12)

Responsabilidades y colaboradores **de diseño**: no obligan a implementar 12 clases independientes ni a duplicar componentes compartidos.

### CRC-US07-01 · PlanMantenimiento

- **Componente / clase candidata:** `PlanMantenimiento`.
- **Responsabilidad:** Conservar versión del plan y frecuencia posterior.
- **Colaboradores:** EtapaMantenimiento, Motocicleta.

### CRC-US07-02 · EtapaMantenimiento

- **Componente / clase candidata:** `EtapaMantenimiento`.
- **Responsabilidad:** Representar número de servicio y regla de vencimiento.
- **Colaboradores:** PlanMantenimiento, CalculadorVencimientos.

### CRC-US07-03 · Motocicleta

- **Componente / clase candidata:** `Motocicleta`.
- **Responsabilidad:** Asociar plan y titular a la unidad atendida.
- **Colaboradores:** PlanMantenimiento, RepositorioMotocicletas.

### CRC-US07-04 · Trabajo

- **Componente / clase candidata:** `Trabajo`.
- **Responsabilidad:** Guardar servicio, fecha real, odómetro y validación.
- **Colaboradores:** RepositorioTrabajos, EtapaMantenimiento.

### CRC-US07-05 · CalculadorVencimientos

- **Componente / clase candidata:** `CalculadorVencimientos`.
- **Responsabilidad:** Determinar próximas fechas a partir de regla aprobada, sin fijar criterio contradictorio.
- **Colaboradores:** EtapaMantenimiento, Trabajo.

### CRC-US07-06 · PoliticaRetraso

- **Componente / clase candidata:** `PoliticaRetraso`.
- **Responsabilidad:** Evaluar fuera de plazo sin bloquear el registro del trabajo.
- **Colaboradores:** CalculadorVencimientos, GestorMantenimiento.

### CRC-US07-07 · SeguimientoView

- **Componente / clase candidata:** `SeguimientoView`.
- **Responsabilidad:** Mostrar etapas y progreso al personal.
- **Colaboradores:** SeguimientoViewModel.

### CRC-US07-08 · SeguimientoViewModel

- **Componente / clase candidata:** `SeguimientoViewModel`.
- **Responsabilidad:** Resolver fechas/estados de respuesta para la interfaz.
- **Colaboradores:** ClienteApiMantenimiento.

### CRC-US07-09 · ClienteApiMantenimiento

- **Componente / clase candidata:** `ClienteApiMantenimiento`.
- **Responsabilidad:** Consultar y registrar historial mediante API C#.
- **Colaboradores:** ControladorMantenimiento.

### CRC-US07-10 · ControladorMantenimiento

- **Componente / clase candidata:** `ControladorMantenimiento`.
- **Responsabilidad:** Validar permisos y enviar órdenes a negocio.
- **Colaboradores:** GestorMantenimiento.

### CRC-US07-11 · GestorMantenimiento

- **Componente / clase candidata:** `GestorMantenimiento`.
- **Responsabilidad:** Actualizar seguimiento sin borrar etapas pasadas.
- **Colaboradores:** RepositorioTrabajos, CalculadorVencimientos.

### CRC-US07-12 · RepositorioTrabajos

- **Componente / clase candidata:** `RepositorioTrabajos`.
- **Responsabilidad:** Obtener historial cronológico y servicios por etapa.
- **Colaboradores:** Trabajo, GestorMantenimiento.
