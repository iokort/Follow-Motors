# US01 — Acceso del gerente / asesor

**Épica:** [E01 — Identidad, acceso y permisos](README.md) · **Issue:** [#16](https://github.com/iokort/Follow-Motors/issues/16) · **Prioridad:** Alta

**Historia:** Como gerente que también ejerce como asesor, quiero entrar al panel operativo con una cuenta habilitada, para gestionar expedientes y citas sin acceso público.

**Dependencias:** US21. **Estado:** implementación de autenticación C# demostrable sin MySQL en una rama de trabajo; integración Angular y revisión final pendientes.

## Criterios de aceptación
- [ ] Con credenciales válidas, entra solo a las acciones de gerencia.
- [ ] Una contraseña incorrecta o una cuenta inactiva no da acceso.
- [ ] La autorización se comprueba desde C#, no por ocultar botones.

## Implementación en C# y trazabilidad

**Alcance de esta entrega:** inicio de sesión del gerente/asesor con una cuenta ficticia configurable en memoria para pruebas de clase. **No necesita MySQL**. No agrega un nuevo controlador: usa el `AuthController` que ya existía para las citas. La autenticación real con MySQL V3 también se conserva. **No se considera toda la US terminada** hasta integrar la pantalla Angular y revisar la autorización general de US21.
