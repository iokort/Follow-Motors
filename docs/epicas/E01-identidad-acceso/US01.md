# US01 — Acceso del gerente / asesor

**Épica:** [E01 — Identidad, acceso y permisos](README.md) · **Issue:** [#16](https://github.com/iokort/Follow-Motors/issues/16) · **Prioridad:** Alta

**Historia:** Como gerente que también ejerce como asesor, quiero entrar al panel operativo con una cuenta habilitada, para gestionar expedientes y citas sin acceso público.

**Dependencias:** US21. **Estado:** especificada; su implementación depende de PR y pruebas reales.

## Criterios de aceptación
- [ ] Con credenciales válidas, entra solo a las acciones de gerencia.
- [ ] Una contraseña incorrecta o una cuenta inactiva no da acceso.
- [ ] La autorización se comprueba desde C#, no por ocultar botones.

## Tarjetas CRC (12)

Las tarjetas siguientes definen **responsabilidad y colaboración propuestas**, no una obligación de implementar 12 clases individuales. Un mismo componente compartido puede aparecer en varias US.

### CRC-US01-01 · Usuario

- **Componente / clase candidata:** `Usuario`.
- **Responsabilidad:** Conservar identidad, hash y estado de la cuenta.
- **Colaboradores:** AutenticacionServicio, RepositorioUsuarios.

### CRC-US01-02 · RolGerente

- **Componente / clase candidata:** `RolGerente`.
- **Responsabilidad:** Representar capacidades administrativas del usuario.
- **Colaboradores:** PoliticaAcceso, Usuario.

### CRC-US01-03 · LoginGerenteView

- **Componente / clase candidata:** `LoginGerenteView`.
- **Responsabilidad:** Mostrar formulario y errores sin datos sensibles.
- **Colaboradores:** LoginGerenteViewModel.

### CRC-US01-04 · LoginGerenteViewModel

- **Componente / clase candidata:** `LoginGerenteViewModel`.
- **Responsabilidad:** Exponer estado de carga y comando de ingreso en Angular.
- **Colaboradores:** ClienteAutenticacion, LoginGerenteView.

### CRC-US01-05 · CredencialesDto

- **Componente / clase candidata:** `CredencialesDto`.
- **Responsabilidad:** Transportar entradas validadas de autenticación.
- **Colaboradores:** ControladorAutenticacion.

### CRC-US01-06 · ClienteAutenticacion

- **Componente / clase candidata:** `ClienteAutenticacion`.
- **Responsabilidad:** Consumir por HTTPS el inicio y cierre de sesión.
- **Colaboradores:** ControladorAutenticacion, LoginGerenteViewModel.

### CRC-US01-07 · ControladorAutenticacion

- **Componente / clase candidata:** `ControladorAutenticacion`.
- **Responsabilidad:** Recibir petición HTTP, validar formato y responder sin filtrar datos.
- **Colaboradores:** AutenticacionServicio.

### CRC-US01-08 · AutenticacionServicio

- **Componente / clase candidata:** `AutenticacionServicio`.
- **Responsabilidad:** Comprobar credenciales y construir la sesión autorizada.
- **Colaboradores:** RepositorioUsuarios, HasherContrasenas.

### CRC-US01-09 · RepositorioUsuarios

- **Componente / clase candidata:** `RepositorioUsuarios`.
- **Responsabilidad:** Buscar cuenta activa y sus roles en MySQL.
- **Colaboradores:** Usuario, AutenticacionServicio.

### CRC-US01-10 · HasherContrasenas

- **Componente / clase candidata:** `HasherContrasenas`.
- **Responsabilidad:** Comparar el secreto suministrado contra el hash almacenado.
- **Colaboradores:** AutenticacionServicio.

### CRC-US01-11 · EmisorSesion

- **Componente / clase candidata:** `EmisorSesion`.
- **Responsabilidad:** Emitir credencial de sesión con caducidad verificable.
- **Colaboradores:** AutenticacionServicio, PoliticaAcceso.

### CRC-US01-12 · AuditoriaAcceso

- **Componente / clase candidata:** `AuditoriaAcceso`.
- **Responsabilidad:** Registrar ingresos y bloqueos sin contraseñas.
- **Colaboradores:** ControladorAutenticacion, Usuario.
