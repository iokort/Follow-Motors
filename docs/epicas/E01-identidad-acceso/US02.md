# US02 — Acceso del cliente habilitado

**Épica:** [E01 — Identidad, acceso y permisos](README.md) · **Issue:** [#17](https://github.com/iokort/Follow-Motors/issues/17) · **Prioridad:** Alta

**Historia:** Como cliente registrado presencialmente, quiero iniciar sesión con credenciales proporcionadas por el gerente, para consultar sus motocicletas vinculadas.

**Dependencias:** US21, US04. **Estado:** especificada; su implementación depende de PR y pruebas reales.

## Criterios de aceptación
- [ ] No existe alta pública de cuentas.
- [ ] Solo ingresan clientes activos vinculados a una cuenta.
- [ ] Nunca se devuelven motos ni historiales de otro propietario.

## Tarjetas CRC (12)

Las tarjetas siguientes definen **responsabilidad y colaboración propuestas**, no una obligación de implementar 12 clases individuales. Un mismo componente compartido puede aparecer en varias US.

### CRC-US02-01 · CuentaCliente

- **Componente / clase candidata:** `CuentaCliente`.
- **Responsabilidad:** Enlazar la identidad de acceso al expediente físico.
- **Colaboradores:** Cliente, Usuario.

### CRC-US02-02 · Cliente

- **Componente / clase candidata:** `Cliente`.
- **Responsabilidad:** Representar expediente con posible cuenta opcional.
- **Colaboradores:** CuentaCliente, RepositorioClientes.

### CRC-US02-03 · LoginClienteView

- **Componente / clase candidata:** `LoginClienteView`.
- **Responsabilidad:** Presentar los campos y errores del acceso cliente.
- **Colaboradores:** LoginClienteViewModel.

### CRC-US02-04 · LoginClienteViewModel

- **Componente / clase candidata:** `LoginClienteViewModel`.
- **Responsabilidad:** Administrar signals de entrada, error y carga.
- **Colaboradores:** ClienteAutenticacion.

### CRC-US02-05 · CredencialesClienteDto

- **Componente / clase candidata:** `CredencialesClienteDto`.
- **Responsabilidad:** Transportar solicitud de ingreso sin datos sobrantes.
- **Colaboradores:** ClienteAutenticacion, ControladorAutenticacion.

### CRC-US02-06 · ClienteAutenticacion

- **Componente / clase candidata:** `ClienteAutenticacion`.
- **Responsabilidad:** Consumir endpoint de sesión desde Angular.
- **Colaboradores:** ControladorAutenticacion, LoginClienteViewModel.

### CRC-US02-07 · ControladorAutenticacion

- **Componente / clase candidata:** `ControladorAutenticacion`.
- **Responsabilidad:** Impedir respuestas reveladoras sobre cuentas existentes.
- **Colaboradores:** AutenticacionServicio.

### CRC-US02-08 · AutenticacionServicio

- **Componente / clase candidata:** `AutenticacionServicio`.
- **Responsabilidad:** Validar cuenta habilitada y comprobar contraseña.
- **Colaboradores:** RepositorioUsuarios, HasherContrasenas.

### CRC-US02-09 · RepositorioClientes

- **Componente / clase candidata:** `RepositorioClientes`.
- **Responsabilidad:** Resolver expediente asociado a la cuenta activa.
- **Colaboradores:** Cliente, PoliticaCuentaCliente.

### CRC-US02-10 · PoliticaCuentaCliente

- **Componente / clase candidata:** `PoliticaCuentaCliente`.
- **Responsabilidad:** Denegar cuenta desactivada o sin habilitación.
- **Colaboradores:** AutenticacionServicio, RepositorioClientes.

### CRC-US02-11 · ContextoCliente

- **Componente / clase candidata:** `ContextoCliente`.
- **Responsabilidad:** Transportar ID de cliente autenticado, no el recibido del navegador.
- **Colaboradores:** ServicioPertenencia.

### CRC-US02-12 · ServicioPertenencia

- **Componente / clase candidata:** `ServicioPertenencia`.
- **Responsabilidad:** Autorizar cada consulta privada contra cliente autenticado.
- **Colaboradores:** ContextoCliente, RepositorioMotocicletas.
