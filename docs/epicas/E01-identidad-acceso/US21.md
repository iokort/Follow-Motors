# US21 — Permisos y aislamiento de datos

**Épica:** [E01 — Identidad, acceso y permisos](README.md) · **Issue:** [#36](https://github.com/iokort/Follow-Motors/issues/36) · **Prioridad:** Alta

**Historia:** Como responsable técnico de seguridad, quiero definir permisos del gerente, mecánico y cliente, para evitar modificaciones o lecturas no autorizadas.

**Dependencias:** Base de identidad; transversal. **Estado:** especificada; su implementación depende de PR y pruebas reales.

## Criterios de aceptación
- [ ] Una cuenta cliente no registra motocicletas ni citas.
- [ ] El gerente puede gestionar mientras el cliente solo ve sus datos.
- [ ] Acceso a un VIN ajeno o a otro expediente se rechaza y queda registrado.

## Tarjetas CRC (12)

Las tarjetas siguientes definen **responsabilidad y colaboración propuestas**, no una obligación de implementar 12 clases individuales. Un mismo componente compartido puede aparecer en varias US.

### CRC-US21-01 · Rol

- **Componente / clase candidata:** `Rol`.
- **Responsabilidad:** Identificar perfil sin mezclar roles del equipo escolar.
- **Colaboradores:** UsuarioRol, RolPermiso.

### CRC-US21-02 · Permiso

- **Componente / clase candidata:** `Permiso`.
- **Responsabilidad:** Representar operación concreta sobre recurso.
- **Colaboradores:** RolPermiso, PoliticaAutorizacion.

### CRC-US21-03 · UsuarioRol

- **Componente / clase candidata:** `UsuarioRol`.
- **Responsabilidad:** Mantener pertenencias de usuario a roles.
- **Colaboradores:** Rol, RepositorioPermisos.

### CRC-US21-04 · RolPermiso

- **Componente / clase candidata:** `RolPermiso`.
- **Responsabilidad:** Relacionar roles con acciones habilitadas.
- **Colaboradores:** Rol, Permiso.

### CRC-US21-05 · PoliticaAutorizacion

- **Componente / clase candidata:** `PoliticaAutorizacion`.
- **Responsabilidad:** Aplicar denegación por defecto en servidor.
- **Colaboradores:** ContextoUsuario, RepositorioPermisos.

### CRC-US21-06 · ContextoUsuario

- **Componente / clase candidata:** `ContextoUsuario`.
- **Responsabilidad:** Obtener identidad autenticada desde sesión válida.
- **Colaboradores:** MiddlewareAutorizacion.

### CRC-US21-07 · MiddlewareAutorizacion

- **Componente / clase candidata:** `MiddlewareAutorizacion`.
- **Responsabilidad:** Bloquear peticiones sin credenciales antes de negocio.
- **Colaboradores:** PoliticaAutorizacion.

### CRC-US21-08 · ServicioPertenencia

- **Componente / clase candidata:** `ServicioPertenencia`.
- **Responsabilidad:** Comprobar que la motocicleta corresponde al cliente actual.
- **Colaboradores:** RepositorioMotocicletas, ContextoUsuario.

### CRC-US21-09 · RepositorioPermisos

- **Componente / clase candidata:** `RepositorioPermisos`.
- **Responsabilidad:** Consultar tablas roles_permisos y usuarios_roles.
- **Colaboradores:** RolPermiso, UsuarioRol.

### CRC-US21-10 · EvaluadorRecurso

- **Componente / clase candidata:** `EvaluadorRecurso`.
- **Responsabilidad:** Combinar rol con propiedad del expediente solicitado.
- **Colaboradores:** ServicioPertenencia, PoliticaAutorizacion.

### CRC-US21-11 · ErrorAccesoDto

- **Componente / clase candidata:** `ErrorAccesoDto`.
- **Responsabilidad:** Devolver 401/403 coherentes y sin detalles sensibles.
- **Colaboradores:** MiddlewareAutorizacion, ControladorPortal.

### CRC-US21-12 · AuditoriaSeguridad

- **Componente / clase candidata:** `AuditoriaSeguridad`.
- **Responsabilidad:** Guardar quién intentó acceder, a qué recurso y resultado.
- **Colaboradores:** PoliticaAutorizacion, ContextoUsuario.
