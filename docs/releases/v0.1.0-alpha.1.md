# Follow Motors — v0.1.0-alpha.1

## Alcance de esta versión preliminar

- Estructura inicial del proyecto y organización del trabajo del equipo SSC.
- API ASP.NET Core (C#) con rutas técnicas de comprobación de salud y conexión local MySQL.
- Frontend Angular 22/TypeScript inicial, aún no funcional como portal de negocio.
- Entorno Docker/MySQL, workflows CI/CodeQL y políticas de revisión de PR.
- Documentación de arquitectura, Scrum, Kanban, historias de usuario, CRC y decisión de negocio de alta presencial.

## Restricciones explícitas

**NO es un despliegue de producción.** No se declaran terminados registro presencial, autenticación real, consulta de motocicletas, agenda, garantías ni operaciones de taller. La aplicación publicada previamente en iokort.com/follow-motors no se reemplaza con esta Release.

La versión nueva será un **portal de asistencia y posventa**; los clientes solo podrán ingresar con alta autorizada en sucursal y acceder a motocicletas propias.
